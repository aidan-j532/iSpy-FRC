Unit Pack Guide

A unit pack is one JSON file in Units/ that is the single source of truth for a measurement convention.

How to use unit packs

  1. Pick the active pack: set "unit": "frc" in Config/config.json, or use Settings / Setup Wizard.
  2. Edit a shipped pack: open Units/frc.json (or metric/imperial), change values, restart iSpy.
  3. Add a new pack: copy an existing JSON, change key, conversion factors, labels, aliases, and optional viewer settings. Save as Units/<key>.json.
  4. Install at runtime: use Add-ons -> Units, or POST /api/units/upload / POST /api/units/write.

Top-level fields

FieldMeaning
schema_versionSchema revision. Use 2.
keyUnique pack ID used by config and unit pickers.
nameHuman-readable name.
descriptionShort explanation.
input_unitPhysical unit a user types.
output_unitPhysical unit published to NT/API/viewer.
input_to_inchesMultiply typed value by this to get inches.
inches_to_outputMultiply inches by this to get published value.
aliasesExtra names that resolve to this pack.

axis

Sign multipliers applied to published values. 1.0 leaves unchanged; -1.0 flips.

{
  "x": 1.0, "y": 1.0, "z": 1.0,
  "roll": 1.0, "pitch": 1.0, "yaw": 1.0
}

Positions use x/y/z. Orientations use roll/pitch/yaw. This does not change the physical frame; it only changes published signs.

labels

{ "input": "ft", "output": "ft", "speed": "ft/s" }

Short UI strings. Derived from units if omitted.

defaults

{ "camera_pitch_deg": 0.0 }

Pitch assigned to newly created cameras. 0 is level and looks forward.

viewer (optional)

Optional 3D viewer settings. Missing fields are filled from built-in defaults.

robot_to_viewer

"robot_to_viewer": ["x", "z", "-y"]

Maps data axes to viewer axes. Must be a signed permutation with determinant +1. Optional; viewer uses default if omitted.

camera_roll_offset_deg / camera_pitch_offset_deg / camera_yaw_offset_deg

Extra rotation applied to camera overlays. Usually 0.

fog_density

Three.js exponential fog density. Scale with scene size: inches needs tiny values, feet/meters larger. 0 disables fog.

axes_size

Length of the solid X/Y/Z axis helper in viewer units.

bounds

{
  "x": { "min": -50.0, "max": 50.0 },
  "y": { "min": -50.0, "max": 50.0 },
  "z": { "min": 0.0, "max": 25.0 }
}

scale

{
  "x": { "min": -50.0, "max": 50.0, "step": 0.1, "default": 1.0 }
}

Viewer scale sliders.

grid

{
  "extent": 100.0,
  "divisions": 80,
  "marker_size": 1.0
}

extent is grid width/depth; derived from bounds if omitted. divisions is line count. marker_size is detection/cube marker size.

camera

{
  "fov": 60.0,
  "near": 0.1,
  "far": 1000.0,
  "position": [75.0, 75.0, 75.0],
  "target": [0.0, 0.0, 0.0]
}

Minimal mental model

  • input_to_inches + inches_to_output = measurement conversion.
  • axis = published sign convention.
  • labels = UI text.
  • defaults = new camera defaults.
  • viewer = optional 3D scene configuration.
If you only care about measurements, keep viewer minimal and let defaults fill the rest.

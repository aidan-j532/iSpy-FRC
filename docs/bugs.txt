BIG PICKLE PROMPT — Stock Ultralytics model download-on-demand + third-party notice

CONTEXT
iSpy currently bundles two stock Ultralytics pretrained checkpoints
(_default_detect.pt, _default_pose.pt) inside iSpy/assets/, copied into
YoloModels/pytorch/ by setup_files() in iSpy/boot/boot.py at every fresh
boot (`boot -f`). These two files are unmodified Ultralytics releases and
are licensed AGPL-3.0 by Ultralytics — separate from iSpy's own PolyForm
Noncommercial 1.0.0 license. Bundling them inside the iSpy repo means the
repo is distributing AGPL-licensed files, which we want to stop doing.
_default_v26_detect_for_fuel.pt is NOT part of this task — it was trained
by the repo owner and stays bundled exactly as-is, no changes.

GOAL
Replace the "bundle + copy from assets/" pattern for _default_detect.pt
and _default_pose.pt with a "download from Ultralytics' own release URLs
on first need" pattern, mirroring the existing style already used in
iSpy/vision/pipelines/yolo_world.py's _ensure_world_model() (download to a
target path, verify size, retry via .part file, don't overwrite a good
existing file). Also drop a generated third-party notice into
YoloModels/pytorch/ whenever either file is downloaded, so a user browsing
their own YoloModels folder sees the AGPL attribution locally, not just in
the repo's root THIRD_PARTY_LICENSES.md.

SCOPE — FILES YOU MAY TOUCH
- iSpy/boot/boot.py (setup_files())
- iSpy/vision/optimizer.py (add a download helper near the top-level
  URL constants, alongside _RKNN_FULL_BASE / _RKNN_FULL_WHEELS style)
- iSpy/config/iSpyConfig.py (default_vision_model()) — read-only unless
  step 4 requires a change; report if you think it does, don't silently
  edit it
- iSpy/assets/ — you MAY delete _default_detect.pt and _default_pose.pt
  from this directory as the final step, but only after confirming the
  download path works
- A new file: iSpy/vision/_default_model_urls.py (or fold into
  optimizer.py if you judge that cleaner — your call, but keep it small
  and isolated)

DO NOT TOUCH
- _default_v26_detect_for_fuel.pt or any code path specific to it
- The RKNN wheel download logic already in optimizer.py
  (_RKNN_FULL_WHEELS, _rknn_wheel_targets) — same pattern, different
  concern, leave it alone
- The subprocess isolation architecture (_convert_worker.py,
  _yoloworld_reparam_worker.py) — unrelated to this task

STEP 1 — Locate the real Ultralytics release URLs
Find the actual asset URLs Ultralytics publishes for the stock YOLO
detect and pose checkpoints on https://github.com/ultralytics/assets/releases
(the same release family yolo_world.py already downloads from via
_WORLD_MODEL_URLS). Determine which specific checkpoint filenames
correspond to whatever _default_detect.pt and _default_pose.pt currently
are (check their file sizes / any existing metadata sidecar
_default_detect_metadata.yaml, _default_pose_metadata.yaml under
iSpy/assets/ if present, to infer which YOLO version/size they are —
report back to me what you find if it's ambiguous; DO NOT GUESS AND SHIP A
DIFFERENT MODEL SIZE THAN WHAT'S CURRENTLY BUNDLED).

STEP 2 — Add a download helper
In optimizer.py (or the new small module), add:

    _DEFAULT_MODEL_URLS = {
        "_default_detect.pt": "<resolved URL from step 1>",
        "_default_pose.pt": "<resolved URL from step 1>",
    }

    def ensure_default_model(name: str) -> Path | None:
        \"\"\"Download a stock Ultralytics checkpoint on demand.

        Mirrors yolo_world.py's _ensure_world_model(): stream to a .part
        file, verify final size >= 1024 bytes, atomic rename, return the
        final Path on success or None on failure (never raises — every
        caller must handle a None gracefully, same contract as the rest
        of the download code in this file).
        \"\"\"

Target path: YoloModels/pytorch/<name>, same directory convention as
today. Log at INFO when a download starts/completes, WARNING on failure
with the reason, exactly like _ensure_world_model does.

STEP 3 — Wire it into default_vision_model() / boot
default_vision_model() in iSpyConfig.py currently assumes
_default_v26_detect_for_fuel.pt or _default_detect.pt already exist on
disk under YoloModels/pytorch/ and just returns a path string. Change the
call site(s) that currently rely on setup_files() having copied the stock
models from assets/ so that, when no user model exists AND the fallback
would be _default_detect.pt or _default_pose.pt, ensure_default_model()
is called first. Boot must not hang or crash if the download fails (e.g.
offline board) — fall back to whatever the existing no-model-found error
path already does (ObjectDetectionPipeline already tolerates self.model
being None; do not change that contract). Report explicitly which call
site(s) you changed and why.

STEP 4 — Drop the third-party notice file
Whenever ensure_default_model() successfully downloads a file, write (if
not already present) YoloModels/pytorch/THIRD_PARTY_NOTICE.txt containing:

    The following files in this directory are stock Ultralytics
    pretrained checkpoints, downloaded directly from
    https://github.com/ultralytics/assets/releases and are NOT part of
    the iSpy codebase. They are licensed AGPL-3.0 by Ultralytics,
    independent of iSpy's own PolyForm Noncommercial 1.0.0 license:

      - _default_detect.pt
      - _default_pose.pt

    Full license text: https://github.com/ultralytics/ultralytics/blob/main/LICENSE

    iSpy never imports Ultralytics code in-process at runtime; these
    weights are loaded by iSpy's dependency-free loader
    (iSpy/vision/yolo_pt.py). See THIRD_PARTY_LICENSES.md at the repo
    root for full details.

Append-only / idempotent: if the file already exists, don't duplicate
content or overwrite user edits to it.

STEP 5 — Remove the bundled copies
Only after steps 1-4 are verified working end to end (a `boot -f` on a
clean checkout actually produces a working _default_detect.pt via
download, not a stale bundled copy): delete _default_detect.pt and
_default_pose.pt (and their metadata sidecars, if those sidecars are
regenerated fresh by the existing metadata_from_pt() path — verify this
before deleting the sidecars specifically) from iSpy/assets/, and update
setup_files() so it no longer expects them there.

REQUIRED OUTPUT STRUCTURE
For each step, report:
1. What you changed (file + function names)
2. What you verified (e.g. "ran boot -f in a clean tmp checkout, observed
   download log lines, confirmed YoloModels/pytorch/_default_detect.pt
   exists and loads via GenericYolo")
3. Anything ambiguous you did NOT resolve yourself — stop and ask rather
   than guessing on: which exact checkpoint size/version to fetch, whether
   metadata sidecars should be regenerated vs. redownloaded, or any
   existing test in iSpy/validations/unit_tests.py that references these
   filenames directly and might need updating (search for
   "_default_detect" and "_default_pose" across the test suite before
   touching anything — report matches, do not silently edit tests).

Do not touch licensing text itself beyond the THIRD_PARTY_NOTICE.txt
content specified above — the wording is final, copy it verbatim.

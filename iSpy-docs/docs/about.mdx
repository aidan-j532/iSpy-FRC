# About iSpy

iSpy is built by **Aidan J**, a student on FRC Team 2207, the Bright Bears.

I built iSpy because I wanted to make computer vision more accessible to anyone (and I was bored). Most of the vision tools I tried assumed you already knew which model to run, how to calibrate a camera, and what to do with the numbers afterwards. iSpy tries to put the camera image, the pipeline, and the results in one place so a new student can see what is happening and change one thing at a time.

## What the project is

iSpy is a camera and vision system for FIRST Robotics Competition robots. It runs camera pipelines on a coprocessor, gives you a local dashboard for working with them, and can send selected results to robot code over NetworkTables.

The [overview](./intro) explains where it fits on a robot, and [Vision Setup](./cameras-and-models) walks through picking a camera and a pipeline.

## Supporting the project

There is no donation page right now. The most useful things you can do are:

- Report bugs with enough detail to reproduce them. The [troubleshooting guide](./troubleshooting) lists the logs and version information that help most.
- Test iSpy on your own hardware and say what worked. Camera quirks and accelerator support are the hardest parts to cover from one team's shop.
- Tell other teams about it, or ask questions on the [Chief Delphi thread](https://www.chiefdelphi.com/t/introducing-ispy-a-students-project-for-advanced-computer-vision/523910).

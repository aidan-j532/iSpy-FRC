# Changelog

All notable changes to iSpy-FRC. Format follows
[Keep a Changelog](https://keepachangelog.com/) - versions align with
`pyproject.toml` (`hatch-vcs` bumps on tagged commits).

## [Unreleased] / next release (current: 1.2.15)

### Added

- **Per-pipeline "needs calibration" declaration + graceful pass-through.**
  `VisionPipeline.requires_calibration()` (defaults to "any `calibration_sections`
  declared", overridable per pipeline) states whether a pipeline must be
  calibrated before it emits detections. While the required calibration is
  missing, `run()` degrades to a plain frame feed (empty detections + raw
  frame - the same `[], frame` pattern already used while optimizing) instead
  of emitting bogus 3D from `focal_length_pixels=1`. ChArUco needs
  `camera_matrix`+`dist_coeffs`; focal needs `focal_length_pixels`/`fov > 0`;
  any one declared section satisfying the pipeline unblocks it. Status shows
  `ready (uncalibrated - passthrough)` so the reason is visible on the health
  page. Object detection, AprilTag, QR and optical flow are gated;
  depth_anything / yolo_world opt out (`calibration_sections = []`).
  `requires_calibration` is also exposed in the `/api/vision_pipelines` payload.
- **Unique per-board mDNS hostname.** The board now advertises
  `ispy-<6 hex>.local` derived from machine-id / MAC / hostname instead of every
  coprocessor claiming `ispy.local`, so two co-procs on one field network do not
  collide. Override with `ISPY_MDNS_HOSTNAME` or `setup_mdns(hostname=...)`
  (`iSpy/boot/setup_service.py`).
- **Visible RKNN target-platform handling.** `ISPY_RKNN_TARGET_PLATFORM` env
  override wins; when the SoC cannot be detected the converter prints a loud
  warning, falls back to `rk3588`, and stamps `target_platform`,
  `target_platform_detected` and a `warning` into the artifact's metadata
  sidecar so a wrong-target artifact is impossible to miss (`iSpy/vision/optimizer.py`).
- **Admin-token-gated mutating web routes.** Plugin upload/create/delete and
  service-control routes reject non-local requests unless `ISPY_ADMIN_TOKEN` is
  set; remote callers then present the matching `X-iSpy-Admin-Token` header
  (`iSpy/web/Backend/PluginStatus.py`).
- **Request/content safety hardening.** Max content length on mutation routes,
  `ensure_disk_space()` pre-flight for recording/conversion writes, and an
  `ISPY_ALLOW_SEARCH_FALLBACK` toggle for calibration dataset search.
- **Bounded camera open.** At most 4 concurrent capture-open attempts
  (`Camera._OPEN_WORKER_MAX`), so a wedged driver cannot spawn unbounded retry
  threads (`iSpy/vision/Camera.py`).
- **Restored unit validation subset.** `iSpy/validations/unit_tests.py`
  (25 tests) runs under `ez.unit_tests()` / `validate_system()` and covers
  AutoOpt recommendations, box results, GenericYolo model selection, and
  metadata round-trips with faked third-party modules.

### Changed

- **BREAKING - NetworkTables default publish format.** `VisionData/vision_data`
  is now a single JSON-string topic (works identically across all pipelines);
  the legacy `FuelStruct[]` struct-array form is opt-in via the add-on's
  `data_type: struct[]` dropdown. Robot-side code consuming the old struct
  schema must parse the JSON topic instead (`NetworkHandler.py` default publish
  set). NetworkTables connect is now non-blocking - a missing robot never
  stalls the vision loop.
- **BREAKING - mDNS hostname no longer `ispy`.** See Added. Set
  `ISPY_MDNS_HOSTNAME=ispy` to restore the legacy name.
- **BREAKING - `GenericYolo` / model config is dict-based** and metadata
  sidecars (`<name>_metadata.yaml`) are the authoritative description of output
  format, task, class names and input size. Models live under
  `YoloModels/<format>/` (a `[size]` subfolder is optional). A missing or
  truncated model degrades to "no detection" instead of crashing
  (`ModelFileError`, `iSpy/vision/genericYolo.py`,
  `iSpy/vision/pipelines/object_detection.py`).
- **Manual converter API moved.** `iSpy.utilities.laptop.AllInOneConvert` is
  gone; use `iSpy.vision.optimizer.convert_model(model_file, target_format,
  input_size, ...)`. Conversion calibration-dir autodetection honors user
  datasets and writes a correct autogenerated `data.yaml` for the root dataset.
- **RKNN wheel download tag fixed.** The toolkit2 wheel base now points at the
  live `RKNN_Wheels` GitHub release (was the non-existent `v1.0.2` tag).
- **Settings page rewrite.** Settings are now atomic-saved (temp-file + rename,
  no partial/corrupt `config.json`), legacy keys auto-migrate on load, and each
  camera boots inside its own try/except so one bad camera cannot take down the
  process.
- RollBack and camera-open worker-thread leaks fixed (drained shutdown,
  bounded retry threads).

### Fixed

- The camera calibration wizard on the Cameras page only offered the ChArUco
  tab (no Focal / FOV) when the Calibrate button was clicked without first
  opening the camera's Edit modal - `pipelineSchemas` was only loaded by the
  modal, so `calibrationSectionsFor()` fell back to `['charuco']`. The wizard now
  loads the pipeline schemas itself before building tabs, and the offline
  fallback carries `calibration_sections` for object_detection. Bonus: since
  schemas now load at page init, the Calibrate button correctly hides for
  pipelines that declare `calibration_sections = []` (depth_anything, yolo_world).
- `Camera._open_capture_bounded` crashed on the very first real camera open
  (`UnboundLocalError: cannot access local variable '_open_worker_live'`) - the
  worker-slot counter was mutated without `global`, so its `+=`/`-=` made it a
  function-local. Added the `global` declarations; new tests cover the success,
  failure, and oversubscription paths and assert the slot always returns to 0.
- `setup_systemd()` no longer hardcodes `User=pi`; the service unit runs as the
  detected user (`SUDO_USER` when the installer runs under sudo and is root,
  otherwise the invoking user, `root` as last resort) so Orange Pi / Ubuntu /
  other SBC images install correctly.
- `_set_rknn_log_level` no longer crashes when listing an unreadable rknn
  package dir (guarded with try/OSError).
- Streamed conversion UI output started immediately even with hashed stdio
  pipes (`_convert_worker.py`).
- Non-blocking NetworkTables connect removed a 15s `time.sleep` retry loop that
  stalled first update (converted to transition-logged async connect).

### Upgrade requirements

1. `git pull` (or reinstall) on the board, then `pip install -e .` /
   `install.sh`.
2. Re-run `iSpy-boot` (`python -m iSpy.boot.boot -f`) - it migrates legacy
   config keys and regenerates any missing metadata sidecars.
3. Re-convert models if an artifact lacks a metadata sidecar (sidecars are
   auto-written by conversion).
4. Update robot code: parse the JSON `VisionData/vision_data` string; if you
   need the struct array set the add-on `data_type` to `struct[]`.
5. If your robot/DS hardcodes `ispy.local`, set `ISPY_MDNS_HOSTNAME=ispy` or
   read the port/hostname from the mDNS/DHCP advertisement.
